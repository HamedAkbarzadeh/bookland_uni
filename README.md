# 📚 بوک‌لند (BookLand) | پلتفرم خرید، فروش و مدیریت کتاب

اپلیکیشن جامع و دوطرفه خرید و فروش کتاب با **فلاتر (Flutter)** در فرانت‌اند و **اکسپرس (Express.js) + مای‌اس‌کیوال (MySQL)** در بک‌اند.

---

## 🌟 ویژگی‌های کلیدی پروژه

1. **مدیریت دوطرفه کتاب‌ها (فروشنده و خریدار)**:
   - هر کاربر می‌تواند کتاب‌های نو، در حد نو یا دست‌دوم خود را با ثبت عنوان، نویسنده، دسته‌بندی موضوعی، قیمت، عکس جلد، توضیحات و وضعیت سلامت برای فروش قرار دهد.
   - امکان مشاهده، جستجوی زنده، فیلتر بر اساس دسته‌بندی، فیلتر وضعیت فیزیکی کتاب (نو، در حد نو، دست دوم) و مرتب‌سازی بر اساس قیمت.
2. **سبد خرید و فرآیند خرید**:
   - افزودن کتاب‌ها به سبد خرید با محاسبه لحظه‌ای قیمت.
   - ثبت آدرس تحویل و انتخاب روش پرداخت.
3. **سیستم کیف پول هوشمند و تسویه خودکار**:
   - اعتبار هدیه اولیه به مبلغ ۵۰۰,۰۰۰ تومان برای کاربران جدید جهت تست تراکنش‌ها.
   - کسر وجه از کیف پول خریدار و واریز خودکار و آنی به حساب فروشنده کتاب پس از ثبت سفارش.
   - امکان افزایش اعتبار (شارژ آنلاین آزمایشی) در هر زمان از طریق پروفایل یا درگاه تسویه حساب.
4. **مدیریت سفارش‌ها و تاریخچه فروش**:
   - تفکیک «خریدهای من» (کتاب‌هایی که کاربر خریده است) و «فروش‌های من» (کتاب‌هایی که دیگران از این کاربر خریده‌اند).
5. **طراحی مدرن و کاملاً راست‌چین (RTL)**:
   - رابط کاربری جذاب با رنگ‌بندی هماهنگ Material 3، پشتیبانی کامل از تاریخ و ارقام فارسی (تومان).
   - صفحات اسپلش متحرک، ورود، ثبت‌نام، خانه، جستجو، جزئیات کتاب، ثبت کتاب برای فروش، سبد خرید، تاریخچه سفارش‌ها، پروفایل و کتاب‌های من.

## 🗂 ساختار پوشه‌های پروژه

```
book-management/
├── backend/                       # بک‌اند نودجی‌اس (Express.js + MySQL)
│   ├── src/
│   │   ├── config/                # اتصال به پایگاه داده MySQL با Connection Pool
│   │   ├── controllers/           # کنترلرهای auth, books, orders, wallet, categories
│   │   ├── middleware/            # احراز هویت JWT و آپلود فایل Multer
│   │   ├── models/                # اسکیما SQL (schema.sql) و لایه DataService
│   │   ├── routes/                # روت‌های API
│   │   ├── seeds/                 # داده‌های اولیه کتاب‌ها، دسته‌بندی‌ها و کاربران تستی
│   │   ├── utils/                 # ماژول رمزنگاری کلمه عبور
│   │   └── server.js              # نقطه ورود و راه‌اندازی سرور روی پورت 5000
│   ├── uploads/                   # ذخیره تصاویر آپلود شده کتاب‌ها
│   ├── docker-compose.yml         # اجرای با یک کلیک دیتابیس MySQL 8.0 و phpMyAdmin
│   ├── package.json
│   └── .env
│
└── frontend/                      # اپلیکیشن چندسکویی فلاتر (Flutter)
    ├── lib/
    │   ├── core/                  # تم رنگی Material 3، ثابت‌های API و فرمت ارقام فارسی
    │   ├── models/                # مدل‌های User, Book, Order, Category, Wallet
    │   ├── providers/             # مدیریت وضعیت با ChangeNotifier (Auth, Books, Cart, Orders)
    │   ├── services/              # لایه سرویس HTTP (ApiService) با ذخیره توکن Bearer
    │   ├── widgets/               # کارت کتاب، تگ‌های دسته‌بندی، فیلد ورودی و برچسب وضعیت
    │   ├── screens/
    │   │   ├── splash_screen.dart # انیمیشن اسپلش و لاگین خودکار
    │   │   ├── auth/              # صفحات لاگین و ثبت‌نام با اکانت‌های دمو
    │   │   ├── main_nav_screen.dart # نوار نویگیشن ۵ تایی با نشانگر سبد خرید
    │   │   ├── home/              # صفحه اصلی با بنر، دسته‌ها و تازه‌ترین کتاب‌ها
    │   │   ├── explore/           # جستجوی زنده با فیلتر وضعیت و مرتب‌سازی قیمت
    │   │   ├── books/             # صفحه جزئیات کتاب، نظرات و فرم ثبت کتاب برای فروش
    │   │   ├── cart/              # سبد خرید، درگاه و شارژ سریع کیف پول
    │   │   ├── orders/            # تب‌های خریدهای من و فروش‌های من
    │   │   └── profile/           # مدیریت کیف پول و لیست کتاب‌های من
    │   └── main.dart
    ├── android/                   # رانر بومی اندروید
    ├── ios/                       # رانر بومی iOS
    ├── windows/                   # رانر بومی ویندوز دسکتاپ
    ├── web/                       # رانر بومی وب
    └── pubspec.yaml
```

## 🚀 راهنمای اجرای سریع پروژه

### ۱. اجرای بک‌اند (Express.js)

```bash
cd backend
npm start
```
سرور به طور پیش‌فرض روی آدرس `http://localhost:5000` بالا می‌آید.

> **نکته پایگاه داده MySQL**:
> - برای اجرای سرور MySQL می‌توانید از XAMPP یا WAMP استفاده کنید، یا به سادگی در پوشه `backend/` دستور زیر را اجرا کنید:
> ```bash
> docker compose up -d
> ```
> پنل phpMyAdmin در پورت `8080` در دسترس خواهد بود.
> - در صورتی که دیتابیس لوکال موقتاً روشن نباشد، سیستم به طور خودکار در حالت حافظه فعال (Active Store) پایدار قرار می‌گیرد تا توسعه و تست شما دچار وقفه نشود.

---

### ۲. اجرای اپلیکیشن فلاتر (Flutter)

```bash
cd frontend
flutter run
```

## 👤 اکانت‌های آزمایشی آماده جهت تست

برای بررسی سریع امکانات خرید و فروش، دو اکانت پیش‌فرض با کلمه عبور `123456` تعریف شده‌اند (دکمه‌های ورود سریع این دو اکانت نیز در صفحه لاگین تعبیه شده است):

1. **اکانت خریدار (سارا امینی)**:
   - ایمیل: `buyer@example.com`
   - رمز عبور: `123456`
   - موجودی کیف پول اولیه: ۱,۲۰۰,۰۰۰ تومان (مناسب برای تست خرید و بررسی کسر وجه)

2. **اکانت فروشنده (رضا کمالی)**:
   - ایمیل: `seller@example.com`
   - رمز عبور: `123456`
   - دارای کتاب‌های فعال برای فروش (عادت‌های اتمی، چشم‌هایش، اثر مرکب و...) و دریافت آنی وجه فروش در کیف پول
