## 🌟 ویژگی‌های کلیدی پروژه

1. **مدیریت دوطرفه کتاب‌ها (فروشنده و خریدار)**:
   - هر کاربر می‌تواند کتاب‌های نو، در حد نو یا دست‌دوم خود را با ثبت عنوان، نویسنده، دسته‌بندی موضوعی، قیمت، عکس جلد، توضیحات و وضعیت فیزیکی برای فروش منتشر کند.
   - جستجوی زنده با مکانیزم Debounce، فیلتر موضوعی بر اساس دسته‌بندی‌ها، فیلتر وضعیت سلامت کتاب و مرتب‌سازی بر اساس قیمت.
2. **سبد خرید و فرآیند سفارش**:
   - افزودن کتاب‌ها به سبد خرید با محاسبه آنی قیمت کل و مدیریت اقلام.
   - ثبت آدرس دقیق ارسال و انتخاب روش پرداخت.
3. **سیستم کیف پول هوشمند و تسویه حساب آنی**:
   - اعتبار هدیه اولیه به مبلغ **۵۰۰,۰۰۰ تومان** برای هر کاربر جدید بلافاصله پس از ثبت‌نام.
   - کسر وجه خودکار از کیف پول خریدار و واریز مستقیم به کیف پول فروشنده کتاب پس از ثبت موفق سفارش.
   - امکان افزایش اعتبار (شارژ شبیه‌سازی‌شده کیف پول) از پروفایل یا درگاه تسویه.
4. **تاریخچه سفارش‌ها و تفکیک خرید/فروش**:
   - تفکیک کامل بخش «خریدهای من» (فاکتورهای خرید کاربر) و «فروش‌های من» (کتاب‌هایی که دیگران از این کاربر خریده‌اند و مبالغ واریز شده).
5. **طراحی مدرن و کاملاً راست‌چین (RTL)**:
   - رابط کاربری جذاب و سازگار با استانداردهای Material 3، پشتیبانی بومی از اعداد و قیمت‌های فارسی (تومان).
   - صفحات اسپلش متحرک، احراز هویت با قابلیت ورود سریع (Quick Demo Login)، خانه، کاوش، ثبت کتاب، سبد خرید، تاریخچه و پروفایل.

قبل از شروع، مطمئن شوید ابزارهای زیر بر روی سیستم شما نصب هستند:

  - یا نرم‌افزارهای لوکال مثل XAMPP / WAMP / MySQL Server
  *(در صورت عدم اجرای MySQL، سرور به صورت خودکار داده‌ها را در حافظه فعال نگه می‌دارد)*

## 🚀 راهنمای گام‌به‌گام راه‌اندازی و اجرای بک‌اند (Backend)

### مرحله ۱: ورود به پوشه بک‌اند
یک ترمینال باز کنید و وارد پوشه `backend` شوید:
```bash
cd backend
```

### مرحله ۲: نصب وابستگی‌ها (Dependencies)
برای دانلود و نصب پکیج‌های npm (مانند Express, MySQL2, JWT, Multer و...):
```bash
npm install
# یا به صورت خلاصه:
npm i
```

### مرحله ۳: ساخت و تنظیم فایل `.env`
یک نسخه از روی فایل نمونه `.env.example` بسازید:
- در لینوکس / مک:
  ```bash
  cp .env.example .env
  ```
- در ویندوز (PowerShell):
  ```powershell
  Copy-Item .env.example .env
  ```
محتوای پیش‌فرض `.env` برای کارکرد لوکال بهینه شده است:
```env
PORT=5000
NODE_ENV=development
DB_HOST=127.0.0.1
DB_PORT=3306
DB_USER=root
DB_PASSWORD=
DB_NAME=book_management
JWT_SECRET=super_secret_book_marketplace_key_2026
JWT_EXPIRES_IN=30d
```

### مرحله ۴: راه‌اندازی پایگاه داده (MySQL)
دو راهکار برای دیتابیس در اختیار دارید:

* **روش اول (توصیه شده با داکر)**:
  در همان پوشه `backend` دستور زیر را بزنید تا MySQL و phpMyAdmin بالا بیایند:
  ```bash
  docker compose up -d
  ```
  - پایگاه داده: روی پورت `3306`
  - پنل مدیریت phpMyAdmin: روی آدرس `http://localhost:8080` (نام کاربری `root` بدون رمز)

* **روش دوم (لوکال با XAMPP / WAMP)**:
  کافیست برنامه XAMPP را باز کرده و سرویس **MySQL** را Start کنید. پایگاه داده‌ای به نام `book_management` ایجاد نمایید.

*(نکته: در صورتی که دیتابیس در دسترس نباشد، سرور بک‌اند به طور خودکار سوییچ کرده و به صورت پایدار در حافظه به سرویس‌دهی ادامه می‌دهد).*

### مرحله ۵: تزریق داده‌های اولیه (Seed Data - اختیاری)
برای پر کردن دیتابیس با کتاب‌های فارسی، دسته‌بندی‌های نمونه و کاربران آزمایشی:
```bash
npm run seed
```

### مرحله ۶: استارت سرور بک‌اند
* **در حالت توسعه (با راه‌اندازی خودکار هنگام تغییر کد)**:
  ```bash
  npm run dev
  ```
* **در حالت معمولی**:
  ```bash
  npm start
  ```

سرور با موفقیت روی آدرس `http://localhost:5000` (یا `http://127.0.0.1:5000`) شروع به کار می‌کند.

## 📱 راهنمای گام‌به‌گام راه‌اندازی و اجرای فرانت‌اند (Flutter)

### مرحله ۱: ورود به پوشه فرانت‌اند
یک ترمینال جدید باز کرده و وارد پوشه `frontend` شوید:
```bash
cd frontend
```

### مرحله ۲: دریافت و نصب پکیج‌های فلاتر
با اجرای دستور زیر تمام کتابخانه‌ها (`provider`, `http`, `intl`, `cached_network_image`, `shared_preferences`) دانلود می‌شوند:
```bash
flutter pub get
```

### مرحله ۳: تنظیم آدرس API (بسیار مهم ⚠️)
فایل زیر را باز کنید:
[`frontend/lib/core/constants/api_constants.dart`](file:///d:/Program/flutter/Project/book-management/frontend/lib/core/constants/api_constants.dart)

بر اساس دستگاهی که قصد اجرای برنامه روی آن را دارید، متغیر `baseUrl` را تنظیم نمایید:
* **اجرا روی شبیه‌ساز اندروید (Android Emulator)**:
  ```dart
  static const String baseUrl = 'http://10.0.2.2:5000/api';
  ```
* **اجرا روی ویندوز دسکتاپ یا وب (Windows Desktop / Chrome)**:
  ```dart
  static const String baseUrl = 'http://127.0.0.1:5000/api';
  ```
* **اجرا روی گوشی فیزیکی (Real Device)**:
  گوشی و لپ‌تاپ باید به یک وای‌فای مشترک وصل باشند. آی‌پی لوکال سیستم خود را جایگزین کنید:
  ```dart
  static const String baseUrl = 'http://192.168.1.X:5000/api'; // آی‌پی لوکال شما
  ```

### مرحله ۴: اجرای برنامه (Run)
دستگاه‌های متصل را بررسی کنید:
```bash
flutter devices
```

سپس برنامه را روی پلتفرم مورد نظر اجرا کنید:
* **اجرا روی نسخه ویندوز دسکتاپ**:
  ```bash
  flutter run -d windows
  ```
* **اجرا روی مرورگر کروم**:
  ```bash
  flutter run -d chrome
  ```
* **اجرا روی شبیه‌ساز یا موبایل اندروید**:
  ```bash
  flutter run
  ```

> 💡 **نکات حین اجرا**:
> - کلید `r` در ترمینال: اجرای **Hot Reload** (اعمال تغییرات در چند میلی‌ثانیه)
> - کلید `R` در ترمینال: اجرای **Hot Restart**
> - کلید `q`: خروج از برنامه

## 🔧 عیب‌یابی و رفع خطاهای رایج (Troubleshooting)

### ۱. خطای مشغول بودن پورت ۵۰۰۰ (`EADDRINUSE: address already in use :::5000`)
این خطا به این معنی است که یک نسخه از سرور نودجی‌اس از قبل در پس‌زمینه در حال اجراست.
- **راه‌حل در ویندوز (PowerShell)**:
  ```powershell
  Get-Process -Id (Get-NetTCPConnection -LocalPort 5000).OwningProcess | Stop-Process -Force
  ```
- **راه‌حل در لینوکس / مک**:
  ```bash
  kill -9 $(lsof -t -i:5000)
  ```

### ۲. عدم برقراری ارتباط فلاتر با سرور (`ClientException: Connection refused` یا `SocketException`)
- مطمئن شوید که سرور بک‌اند اجرا شده و پیام `🚀 Book Management & Marketplace Server Running!` را در ترمینال می‌بینید.
- آدرس `baseUrl` در [`api_constants.dart`](file:///d:/Program/flutter/Project/book-management/frontend/lib/core/constants/api_constants.dart) را بررسی کنید:
  - اگر در شبیه‌ساز اندروید هستید، حتماً از `10.0.2.2` استفاده کنید (نه `localhost`).
  - اگر روی گوشی فیزیکی هستید، مطمئن شوید فایروال ویندوز پورت ۵۰۰۰ را مسدود نکرده باشد.

### ۳. عدم اعمال پکیج‌های فلاتر بعد از دریافت
اگر پکیج جدیدی اضافه کردید یا خطای وابستگی دیدید:
```bash
cd frontend
flutter clean
flutter pub get
```
